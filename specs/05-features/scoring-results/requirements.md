# Scoring and Results Requirements

- **SCORE-001 — Undefended Attack:** Award Wolf 2 points when Sheep cannot defend an attack.
- **SCORE-002 — Successful Defense:** Award Sheep 1 point for a successful matching-category defense.
- **SCORE-003 — Challenge Bonus:** Award Sheep 1 additional point when the corresponding challenge succeeds.
- **SCORE-004 — Server Authority:** Calculate and mutate scores only through the Game Engine on the Host.
- **SCORE-005 — Human Outcome:** Participating players or the Host determine challenge success or failure; only the Host records the outcome in authoritative game state.
- **SCORE-006 — Final Result:** After all rounds, publish final scores and the winner or draw to all connected players.
- **SCORE-007 — No Manual Edits:** Regular players cannot directly change scores or declare a winner.
