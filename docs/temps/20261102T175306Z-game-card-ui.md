# GameCard UI Run

## Scope

Implemented the reusable card front/back, Wolf challenge selection, and the shadcn/ui Base UI Sheet used to choose a challenge. This repository does not yet have a game-selection screen that mounts GameCard, so this change provides the reusable component API for that screen.

## Design References

- Card front: Figma node `2122:747`, 200×320px card, Judson typography, category sticker, challenge count.
- Card back: Figma node `2208:1089`, same frame with “Thử thách”, selected challenge text, and category sticker.
- Challenge picker: shadcn/ui Base UI Sheet API, shown from the bottom on Wolf selection.
- Reused the existing category sticker assets in `web-game/public/assets/card-stickers/`.

The Figma back-frame context returned its reference composition; the screenshot endpoint was rate-limited before a direct screenshot comparison. The back was rendered locally and adjusted to keep longer challenge copy clear of the sticker.
